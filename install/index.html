Install an APK on Android

Apps on this site are downloaded as APK files and installed directly, not through Google Play. This takes about a minute.

  1. Download the APK from the app's page, using your phone's browser. Note the version you chose.
  2. Allow installs from your browser. When Android asks, open Settings and turn on Allow from this source for the browser or file manager you used. You can turn it off again afterwards.
  3. Open the file from your notifications or the Downloads folder and tap Install.
  4. Updating: install the newer APK over the old one. Your data stays, as long as it is the same app and was signed the same way. If Android refuses the update, uninstall the old version first; this removes its data.

Check the file (optional)

Each version lists a SHA-256 checksum. If it does not match, do not install the file.

  • On Windows, in PowerShell: Get-FileHash .\App.apk -Algorithm SHA256
  • On macOS or Linux: shasum -a 256 App.apk
  • On Android: a file-manager or hash-checker app that shows SHA-256.

Good to know

  • Builds marked Dev build are debug-signed test versions and may be rough.
  • Android may warn that the app is from an unknown source. That is expected for apps outside Google Play.
