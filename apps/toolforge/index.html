About

An offline document library. Import PDFs, images, EPUBs and text files, then read, organise and work on them without an internet connection.

Release builds ask for no internet permission. Camera scanning and PDF tools (merge, extract pages, rotate, crop, compress) are planned in later versions.

It is in early development, so features will change between versions.
